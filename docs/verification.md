# Проверка этапа 1

## Реально выполнено

- Node: 58 тестов модели, каталога, JSON и ZIP — все прошли.
- Python/Chrome: 51 тест интерфейса, редактора и изображения — все прошли.
- Полный путь: создать здание → добавить зелёный бонус и красный штраф → создать независимый ресурс → изменить владельца → создать вассальный дом → перезагрузить → скачать JSON → импортировать изменённый JSON → скачать сайт ZIP → распаковать в новую папку → открыть под проектным префиксом.
- Чистый release ZIP без тестовых объектов отдельно распакован и проверен через HTTP на `/` и `/gilneas-atlas/`: все assets ответили без ошибок, локация открылась, новый объект сохранился после перезагрузки.
- Портретные экраны 390×844 и 360×780, короткий альбомный экран 844×390: панели взаимоисключающие, горизонтального overflow нет, последние поля и сохранение достижимы, шапка остаётся доступной.
- Камера: настоящий wheel, drag и touch-pinch, постоянные размеры меток, отмена RAF-перелёта после ручного ввода.
- Неактивные зоны: ни одна опубликованная метка не стоит внутри маски, создание/перенос точек проверяет маску. Настоящие щелчки создали локацию и полигон, их данные пережили перезагрузку; сброс восстановил baseline.
- Источники: 186 реально сохранённых supporting excerpts программно совпали с соответствующими извлечёнными текстами с учётом Markdown-ссылок; неподтверждённые владельцы не заполнялись.
- Исходные PNG сохранены отдельно, их SHA-256 совпали с исходной парой.

## Состав релиза

39 меток локаций, 17 персоналий в хронике, 10 держав/домов (включая 3 суверенные державы), 9 редактируемых сценарных областей влияния, 64 источника. В опубликованном baseline нет вымышленных зданий, ресурсных объёмов или модификаторов: их добавляет автор.

## Ограничения

- Это статическая карта: черновик локален до экспорта и публикации в GitHub. Совместный backend не добавлен.
- Геометрия областей влияния — сценарная схема, а не канонический довоенный кадастр.
- Поздние городские кварталы и поселения отмечены реконструкциями; барон Сребролен, Уолден и другие с недоказанной ранней датой не назначены довоенными владельцами.
- Ретушь стены и замена кратера Даларана — картографическая адаптация современного рендера. Не утверждается, что это восстановленные исторические пиксели.
- Увеличение до 4870×7290 выполнено Lanczos с коррекцией читаемости; новые детали не сгенерированы.
