# Перенос координат при смене карты

- Новая карта имеет иной обрез кадра, а не независимый масштаб по двум осям. Сопоставление SIFT + RANSAC даёт 1217 согласованных признаков из 1259, медианную ошибку 0.312 пикселя, 95-процентную 1.355 пикселя. Это геометрическая проверка, не семантическая идентификация всех малых объектов.
- Координаты стандартных объектов пересматриваются по видимым зданиям; крупный Даларан, Темная Гавань и ранее неправильно отмеченный северный маяк уточняются отдельно. Столица Лордерона частично обрезана верхом новой карты.
- Ручные точки автора переводятся той же проективной матрицей, а неизменённые исходные точки принимают проверенные новые координаты. Имена, дома, владельцы, текст и вложенные объекты не меняются.
- Прежние полигоны переводятся отдельно. Ручная `territoryGrid` переносится обратным выбором ближайшей исходной ячейки; нулевые владельцы/ручные стирания не заполняются по семенам меток. Точность ограничена размером исходной и новой сетки.
- Если новая обрезка исключила авторскую точку, миграция не должна тихо удалять или зажимать координату: исходный черновик остаётся нетронутым с понятным предупреждением.
- На загрузке localStorage не перезаписывается. JSON/ZIP и дальнейшая авторская запись сохраняют перенесённый полный снимок; исходную резервную копию можно скачать до применения спорных изменений.
