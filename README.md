# Атлас королевства Гилнеас

Статический русскоязычный атлас World of Warcraft: карта, реестр владений, области влияния держав и вассалов, пергаментные досье, редактор локаций, зданий, ресурсов и текстовых модификаторов.

Этап 1: 39 локаций, 17 персоналий, 10 держав/домов, 9 сценарных областей и 64 источника. Основной лорный справочник — Wowpedia; русские названия проверены отдельно по игровой локализации. Неизвестные довоенные владельцы оставлены пустыми. Ресурсы и здания без подтверждённых записей не заполняются вымышленными цифрами.

## Запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. Сервер отдаёт только статические файлы; backend, токены и пароль для редактора не нужны. `file://` не поддерживается для ES-модулей и загрузки JSON: используйте HTTP или GitHub Pages.

## Редактирование и сохранение

- Редактор сохраняет полный снимок в `gilneas-atlas-draft-v1` в localStorage этого сайта.
- JSON содержит локации, дома/сюзеренов, объекты, отдельные бонусы и штрафы, территории, знать и источники.
- Локальное редактирование не изменяет общий сайт. Экспорт ZIP сохраняет текущий снимок под `assets/data/atlas.json`; распакуйте его в корень репозитория и закоммитьте изменения.
- Сброс локального черновика восстанавливает опубликованный снимок, а не удаляет данные у остальных игроков.
- Это не система совместного редактирования. Права на общую публикацию определяются GitHub, а не клиентским JavaScript.

## GitHub Pages

В Settings → Pages выберите **GitHub Actions**. Workflow `.github/workflows/deploy-pages.yml` проверяет синтаксис модулей и наличие runtime-файлов, затем публикует `index.html`, `.nojekyll` и `assets/` из корня. Все runtime paths относительные, поэтому поддерживается проектный адрес `/gilneas-atlas/`.

Архив из редактора включает скрытые файлы. На macOS `⌘⇧.` показывает их в Finder. Экспорт не содержит учётные данные GitHub.

## Исторический контракт

Период — после Второй войны, но до выхода Гилнеаса из Альянса Лордерона и сооружения Стены Седогрива. Точный год не придуман. Wowpedia — основной источник; зеркала Warcraft Wiki помечены отдельно при недоступности оригинала.

Довоенная кадастровая карта Гилнеаса не сохранилась в источниках. Сценарные области влияния и поздно описанные поселения — реконструкции, а не новые канонические границы. Если имя владельца для выбранного периода не подтверждено, поле пустое и досье сообщает «Не установлен». Титул из Cataclysm не считается доказательством того же титула до стены.

Подложка получена из предоставленного пользователем рендера. Видимая поздняя стена и место современного кратера адаптированы локальной картографической реконструкцией; это не восстановленные канонические пиксели. Неактивные районы построены по отличиям корректирующего изображения, сохраняют берег и рельеф под дымкой. Географические координаты всегда находятся в оригинальном пространстве 3247 × 4860. Вывод увеличен до 4870 × 7290 методом Lanczos с умеренным повышением яркости, цвета и резкости. Это повышение читаемости, а не генерация новых деталей.

## Проверка

```sh
npm test
npm run check
```

Python/Playwright tests and processing use Pillow, NumPy, SciPy and Playwright. Install them in a virtual environment rather than in the OS Python. Development scripts and screenshots do not enter the Pages artifact.

Подходы камеры, локальных снимков, экспорта и мобильных панелей развивают предыдущий проект [Naitroud/Naitroud.github.io](https://github.com/Naitroud/Naitroud.github.io/). Галактические данные и sci-fi интерфейс не перенесены.

World of Warcraft, Warcraft и игровая графика принадлежат Blizzard Entertainment. Это неофициальный некоммерческий фанатский атлас, не связанный с Blizzard. Тексты — русскоязычные пересказы с ссылками на Wowpedia; архивные цитаты принадлежат авторам источников. Пользовательский исходный рендер сохранён в локальном архиве, а не включён как огромный дубликат в runtime сайта.
